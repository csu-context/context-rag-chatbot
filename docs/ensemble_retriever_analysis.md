## 분석 및 결론

### BM25 단독
- 키워드 매칭에 강점, "휴학", "복학" 등 정확한 단어가 있을 때 높은 점수
- 의미적으로 유사하지만 단어가 다른 경우 점수 낮음

### Vector 단독
- ChromaManager 연동 후 의미 기반 검색 가능
- 키워드가 정확히 없어도 문맥상 관련 문서 검색 가능

### 하이브리드 RRF
- BM25와 Vector 결과를 순위 기반으로 병합
- 한쪽 엔진 결과가 없어도 다른 엔진 결과 정상 반환
- ChromaManager 연동 시 키워드 + 의미 검색 시너지 기대

## 최적 가중치 제안
- 학칙/규정 질문: 키워드 매칭이 중요하므로 `HYBRID_WEIGHT_BM25=0.6`, `HYBRID_WEIGHT_VECTOR=0.4` 권장
- 일반 질문: `HYBRID_WEIGHT_BM25=0.4`, `HYBRID_WEIGHT_VECTOR=0.6` 권장
