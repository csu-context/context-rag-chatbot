# 앙상블 리트리버 비교 분석서 (이슈 #46)

## 개요
BM25 단독, Vector 단독, 하이브리드 RRF 방식의 검색 결과를 비교 분석합니다.
LangChain 없이 RRF 알고리즘을 직접 구현하여 두 엔진의 결과를 병합합니다.

## 테스트 환경
- 데이터: `data/processed/data.json` (조선대학교 학칙 샘플 4개 청크)
- BM25 엔진: `rank_bm25.BM25Plus` + `kiwipiepy.Kiwi` 형태소 분석
- Vector 엔진: ChromaManager (테스트 시 미연결)
- RRF 파라미터: `RRF_K=60`, `HYBRID_WEIGHT_BM25=0.5`, `HYBRID_WEIGHT_VECTOR=0.5`

## 엔진별 특성 분석

### BM25 단독
- 키워드 매칭에 강점, "휴학", "복학" 등 정확한 단어가 있을 때 높은 점수
- 의미적으로 유사하지만 단어가 다른 경우 점수 낮음
- 형태소 분석(kiwipiepy)으로 조사/어미 제거 후 핵심 명사 기반 매칭

### Vector 단독
- ChromaManager 연동 후 의미 기반 검색 가능
- 키워드가 정확히 없어도 문맥상 관련 문서 검색 가능
- 현재 테스트 환경에서는 미연결 상태

### 하이브리드 RRF
- BM25와 Vector 결과를 순위 기반으로 병합 (1 / (k + rank))
- 동일 문서가 양쪽에서 검색될 경우 RRF 점수 합산
- chunk_id 기반 중복 제거로 데이터 유실 방지
- 한쪽 엔진 결과가 없어도 다른 엔진 결과 정상 반환

## 최적 가중치 제안

| 질문 유형 | HYBRID_WEIGHT_BM25 | HYBRID_WEIGHT_VECTOR | 근거 |
|-----------|-------------------|---------------------|------|
| 학칙/규정 | 0.6 | 0.4 | 키워드 정확도 중요 |
| 일반 질문 | 0.4 | 0.6 | 의미 검색 중요 |
| 기본값 | 0.5 | 0.5 | 균형 유지 |

## 결론
ChromaManager 연동 완료 시 키워드 + 의미 검색 시너지로 검색 품질 향상 기대.
현재는 BM25 단독으로도 학칙 관련 키워드 질문에 높은 정확도를 보임.
