# 📑 메타데이터 설계 가이드 (v1.0.0)

우리 프로젝트의 RAG 시스템에서 검색 정확도를 높이기 위해 정의된 메타데이터 규격입니다. 모든 전처리 모듈은 이 가이드를 준수해야 합니다. 🚀

---

## 🛠 필수 구현 규칙 (중요!)

### 1. 경로 관리 (Path Management)
운영체제(Windows/Mac) 간 호환성을 위해 **반드시 `pathlib` 라이브러리**를 사용합니다.
- **Good:** `src_name = Path(file_path).name`
- **Bad:** `file_path.split("\\")[-1]`

### 2. 페이지 번호 인덱싱 보정 (pg_num)
대부분의 라이브러리(PyPDFLoader 등)는 페이지를 0부터 시작하지만, **저장할 때는 반드시 `+ 1`을 하여 1부터 시작**하도록 보정합니다.
- 예: PDF 1페이지 -> `pg_num: 1`

### 3. 인코딩 규칙
파일명이나 텍스트 처리 시 반드시 **UTF-8** 인코딩을 사용합니다.

---

## 필드 상세 설명

| 필드명 | 타입 | 필수 여부 | 설명 |
| :--- | :--- | :--- | :--- |
| **source_id** | String | 필수 | 파일 고유 식별자 (파일명+수정시간 해시) |
| **src_name** | String | 필수 | 원본 파일명 (예: manual.pdf) |
| **pg_num** | Integer | 필수 | 문서 내 실제 페이지 번호 (1-based) |
| **parent_id** | String | 선택 | 계층적 청킹 시 부모 청크 ID |
| **chunk_id** | String | 필수 | 현재 청크의 고유 순번 |
